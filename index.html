    JWT 上线

    JWT 解码工具

    • 签名暂不校验，明确标注「未验证」状态

    URL 上线

    URL 编解码工具

    • encodeURIComponent / encodeURI 双模式切换
    • 批量按行编解码，空行保留
    • 完整 URL 自动拆解为 protocol / host / path / query 表格
  4. v0.4
    Base64 上线

    Base64 编解码工具

    • 文本 ↔ Base64 双向转换，UTF-8 安全
    • URL-safe 变体支持
    • 文件 → Base64 与 Base64 → 文件 双向直转，自动嗅探 MIME
  5. v0.3
    JSON 上线

    JSON 格式化工具

    • 美化 / 压缩 / 键排序 / 转义 / 反转义
    • 错误自动定位，可调缩进（2 / 4 / Tab）
    • 支持粘贴自动美化、⌘/Ctrl + B、⌘/Ctrl + M 快捷键
  6. v0.2
    去水印上线

    豆包图片去水印

    • 手动框选 / 自动扫描 / 灰白文字 三种擦除策略
    • 处理前后滑动对比，原始分辨率导出 PNG
    • 全程浏览器本地处理，不上传任何字节
  7. v0.1
    首发

    站点脚手架与时间戳互转

    • Unix 时间戳 ↔ ISO 8601 ↔ 自然语言时间互转
    • 多时区切换、当前时间实时刷新
    • 建立站点视觉系统与工具页通用框架
